# Icons8 assets

The hero uses locally stored Icons8 PNG icons (48px originals, displayed at 22px).

- arrow-up-right.png: https://img.icons8.com/ios-filled/48/ffffff/up-right-arrow.png
- menu.png: https://img.icons8.com/ios-glyphs/48/142D4E/menu--v1.png

Source and license: https://icons8.com/license
A visible Icons by Icons8 attribution is included in the page footer for free usage.
Use the reusable Blade component: <x-icon name="arrow-up-right" /> or <x-icon name="menu" />.

The hero currently uses a labelled portrait placeholder. Set the approved image's public asset path in config/brand.php until the media admin is implemented. Navigation and CTA buttons open an explicit build-stage notice; no enquiry is submitted.
